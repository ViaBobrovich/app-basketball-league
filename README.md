# app-basketball-league

## Алгоритм использования
1. Создать матч (выбрав команды, время, место)
2. Создать в этом матче событие (игрок А сделал бросок с определённой позиции в определённое время)


## Что в этот момент происходит
1. Это событие отразится в статистике игроков
2. Это событие отразится в статистике команды
3. Eсли это привело к увеличению счёта и его команда имеет больше очков - это отразится в графе "победы / поражения"
4. Так же отразится в средней статистике ТОП3, если игрок вошёл в рейтинг, благодаря созданному событию

ps. с одной стороны на практике это не актуально, тк данные и логика должно быть на сервере. Но для практики было полезно и интересно
