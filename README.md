# app-basketball-league

## Алгоритм использования
1. Создать матч (выбрав команды, время, место)
2. Создать в этом матче событие (игрок А сделал бросок с определённой позиции в определённое время)

a. Это событие отразится в статистике игроков
b. Это событие отразится в статистике команды
c. Если это привело к увеличению счёта и его команда имеет больше очков - это отразится в графе "победы / поражения"
d. Так же отразится в средней статистике ТОП3, если игрок вошёл в рейтинг, благодаря созданному событию

ps. с одной стороны на практике это не актуально, тк данные и логика должно быть на сервере. Но для практики было полезно и интересно
